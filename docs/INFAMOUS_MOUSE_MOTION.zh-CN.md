# 鼠标体感操作

使用现有 Windows SDL3 输入，不需要额外驱动或手柄。
照常运行 `run-infamous.bat`，进入游戏的体感操作提示后：

启动选择窗口会同时显示鼠标体感提示，并提供“在游戏左上角显示帧数（FPS）”选项。
FPS 默认开启；选择会保存到 `infamous-locale.json`，下次启动继续使用。

| 操作 | 功能 |
|---|---|
| F6 | 开启鼠标体感并模拟竖握；再次按下退出 |
| 移动鼠标 | 调整姿态和方向 |
| 快速来回移动鼠标 | 产生摇晃加速度 |
| 按住鼠标左键 | 按住游戏手柄的 R2（喷漆） |
| F7 | 将鼠标姿态回正，清除尚未处理的位移 |
| Esc | 退出鼠标体感并释放光标 |

开启后鼠标隐藏并限制在游戏窗口内，窗口标题显示操作提示。切换到其他窗口、打开
Insert 设置菜单或进入文字输入时自动退出，恢复焦点后不会自行重新捕获鼠标。
普通 Xbox/键盘按键继续有效；关闭体感后鼠标不向游戏发送体感或 R2 输入。

默认灵敏度为 `0.003` 弧度/像素。需要调整时，可在启动游戏的当前命令行中设置
`BB_MOUSE_MOTION_SENSITIVITY`（范围 `0.0001`–`0.02`）；无需修改系统环境变量。

## 诊断与验证

F10 照常记录问题。自动采集的 `input.txt` 新增 `# MOTION` 行，最多 20 Hz，
包括姿态四元数、以 g 为单位的加速度和以 rad/s 为单位的角速度，仍使用原来的轮换大小限制。
F9 输入录制新增这 10 个浮点字段，旧的 8 列按键回放文件仍可读取。

供开发验证的 `BB_PAD_FILE` 支持 `motion=1`、`motion=0`、`motion_center`、
`mouse_dx=N`、`mouse_dy=N`；每次文件更新的位移只消费一次。它与鼠标使用同一转换函数，
仅用于显式启用的诊断回放，不属于日常操作。文件中的 `r2` 可用于验证喷漆按键。

实现将鼠标姿态转换成一致的方向、重力分量和角速度；快速加减速生成有界的摇晃分量。
游戏调用重置方向时只改变参考姿态，不改变物理重力方向。纯计算和窗口事件测试分别覆盖
采样频率、归一化、非法数值、回正、停下后收敛、输入隔离和焦点释放。

SDL 鼠标捕获只由游戏窗口线程操作，避免从游戏工作线程调用窗口 API：
[SDL 相对鼠标模式](https://wiki.libsdl.org/SDL3/SDL_SetWindowRelativeMouseMode)。
