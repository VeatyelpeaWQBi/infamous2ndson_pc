Local reverse-analysis tooling and measurement fixes (2026-10-09):
  vk_gpu_profiler recycles timestamp query slices only after their exact GPU
  submission completes; it does not wait for queries or reset in-flight slots.
  vk_pipeline_cache can export original GCN even on a translated-cache hit
  when BB_DUMP_SHADERS=1. The offline test decoder uses the existing production
  GCN decoder. No game program or shader package is changed.
  BB_READBACK_SPECULATIVE is a diagnostic control for speculative copies only;
  demand-page learning, precise ownership and coalesced downloads stay active.
  Experimental async-prefetch/interval controls remain off by default after
  negative end-to-end measurements. The GPU dirty-reuse experiment was removed
  after an A/B/B/A run showed no reproducible gain.
  See docs/INFAMOUS_REVERSE_ANALYSIS.2026-10-09.zh-CN.md for evidence and limits.
  Local opt-in BB_BIND_TIMER_STRIDE samples five high-frequency bind/select
  diagnostic timers with independent PRNG streams; default 1 keeps exact timing.
  Real-game repeats reduced command-thread CPU cost but did not establish FPS
  gains. Synchronization waits and frame intervals remain exact.
  Readback telemetry separates guest-thread waits from GPU command-thread waits
  and records command round trips/retries without changing synchronization.
  BB_OCCLUSION_TRACE is bounded, default-off query consumer diagnostics; it does
  not replace query results or remove game rendering.

AYOUB readonly synchronization memo experiment (2026-10-09):
  Derived from 153a5aa MemoryTracker::GetCpuVersions and BufferCache::sync_memos.
  BB_BUFFER_SYNC_MEMO=1 is opt-in. Local regions are 4 MiB, not 16 MiB;
  readonly raw-buffer bindings compare CPU-write tokens and current arena
  pointers. CPU faults/window invalidation advance tokens before unprotecting.
  Writable/texel bindings and BB_HOT_PAGES bypass the memo. No resource preload,
  game modification, write-discard or weaker GPU readback is introduced.
  See docs/AYOUB_DEEP_PERFORMANCE_REVIEW.2026-10-09.zh-CN.md for measurements.
